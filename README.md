# Snanswer · AI 面试辅助助手

![release](https://img.shields.io/github/v/release/simpleqt/snanswer)
![license](https://img.shields.io/github/badge/license-CC%20BY--NC%204.0-blue)

**专为面试场景打造的 AI 辅助助手**：实时截屏解题、监听面试官提问自动生成建议回答、答案推送到手机端查看——全程电脑端零键盘输入。悬浮窗对屏幕共享软件隐身、不抢占焦点，支持多家大模型供应商一键切换。

> 界面截图整理中，欢迎通过 Issue/PR 补充实测截图。

## 它是怎么工作的

```
快捷键 / 手机按钮 / 鼠标双击
        │
        ▼
截取整块屏幕（题目所在的浏览器 / IDE / 考试页面）
        │  └─ 若语音转录已开启，转写文字会连同截图一起提交
        ▼
视觉大模型流式分析
        │
        ▼
答案展示在隐身悬浮窗 / 手机浏览器（局域网）
```

三个最容易被误解的点，先说清楚：

1. **截屏截的是「题目」，不是本工具的窗口。** 截图对象是整块屏幕上的内容；本工具窗口被主动排除在所有屏幕捕获之外（`setContentProtection`）。这既是对会议软件隐身的基础，也避免自己的答案混进下一张截图干扰 AI 判断。「截不到工具窗口」正是预期的隐身效果，而不是故障。
2. **窗口隐藏不影响使用。** 窗口被隐藏（手动快捷键，或开启手机显示模式后自动隐藏）时，截屏、追问、实时助手照常工作，解答照常生成并推送到手机端。想找回窗口：按「隐藏/显示窗口」快捷键、点手机端「显示电脑窗口」，或点系统托盘图标。
3. **语音 → AI 解答有两条链路：**
   - **实时面试助手（全自动）**：开启后持续监听，识别到「面试官问完了」（静音 + 问句特征）就自动生成建议回答，全程零按键；
   - **语音转录（手动辅助）**：开启后只负责把声音转成文字积累下来，在你按截屏快捷键时随截图一起提交给 AI（适合听力题、面试官口头补充条件等场景）。**转录本身不会触发解答**——手动链路始终以截图为核心。

## 核心能力

- **截屏解题**：快捷键抓取屏幕（可附带电脑声音的实时转录文字），发送给视觉大模型分析，流式展示解答；支持追加截图与追问，保持对话上下文连续
- **多供应商配置档案**：内置 DeepSeek / 硅基流动 / 百炼 / 智谱 / Kimi / OpenRouter / OpenAI 预设，每家独立保存地址、Key、模型与思考配置，一键或快捷键切换；支持从服务商自动拉取模型列表
- **思考控制**：按服务商注入正确参数（DeepSeek/智谱 `thinking`、OpenAI `reasoning_effort`、通义系 `enable_thinking` 等），支持 低/中/高 思考强度
- **手机显示模式**：电脑端在局域网启动服务，手机扫码实时查看解答；截屏、追加截图、切换场景、深度思考均可在手机端操作；全屏纯显示、屏幕常亮、字号可调
- **实时面试助手**：持续监听面试官提问（语音转写实时可见），自动识别「问完了」并实时生成建议回答，电脑/手机双端时间线展示，历史自动压缩
- **点击截屏**：鼠标左键双击 / 单击触发截图（可选档位，避免快捷键被键盘监听捕获）
- **透明答案模式**：背景完全透明，仅答案文字悬浮于屏幕，字体颜色可调，配合鼠标穿透 + 滚轮滚动阅读
- **场景化提示词**：预置「解算法题」「英语考试」「通用问答」等场景一键切换，支持自定义场景
- **自动更新**（Windows）：自动检查 GitHub 最新版本并后台下载，退出时按原安装路径覆盖安装
- **屏幕分享隐身 + 不抢占焦点**：被要求共享屏幕时对方看不到本窗口；置顶半透明展示，原页面不失焦

## 适用场景

- **技术面试 / 编程笔试**：实时截取屏幕题目，秒级给出解题思路与代码（Python、JavaScript、Java、C++ 等主流语言）；实时助手监听面试官追问，自动生成建议回答
- **在线笔试 / 测评**：单选、多选、解答等题型一键切换对应场景；答案推送到手机，电脑端零键盘输入
- **英语面试 / 机试**：切换「英语考试」场景，结合语音转录处理听力与口语题
- **其他场景**：自定义提示词场景任意扩展

## 如何使用

> 直接使用：前往 [Releases](https://github.com/simpleqt/snanswer/releases) 下载最新版（Windows 为向导式安装、可选安装路径、支持自动更新；macOS 下载 dmg 拖入应用程序，首次打开右键 App →「打开」）。

### 1. 安装依赖并启动

项目运行依赖 [Node.js](https://nodejs.org/zh-cn/download)：

```bash
$ npm install
$ npm run dev
```

### 2. 配置 AI 服务商

进入「设置 → AI 设置」：

1. **模型服务商**下拉选择预设（如 DeepSeek），地址与推荐视觉模型自动填入
2. 填入该服务商的 **API Key**（国内推荐[硅基流动](https://cloud.siliconflow.cn/i/SG8C0772)或[阿里百炼](https://help.aliyun.com/zh/model-studio/get-api-key)，支持支付宝；海外可用 [OpenRouter](https://openrouter.ai/) / OpenAI）
3. 模型下拉点「**获取模型列表**」可拉取服务商真实模型清单校验 Key 是否有效
4. 点「**保存当前**」把这套配置存为方案——之后用切换供应商快捷键即可在多家供应商之间秒切（某家限流/欠费时立刻切备用）

> 也可以在项目根目录创建 `.env` 文件预配置（`API_BASE_URL` / `API_KEY` / `MODEL`），程序启动后作为默认值。

### 3. （可选）语音转录

实时把电脑播放的声音（面试官讲话、听力音频）转为文字，截图时自动附给 AI。需配置[阿里百炼](https://help.aliyun.com/zh/model-studio/get-api-key) API Key，快捷键 `Alt+T` 开关。

> 平台说明：系统声音捕获仅 Windows 支持；macOS 会自动改用麦克风收音并提示。

### 4. （可选）手机显示模式

把解答「搬」到手机上，答题全程电脑零键盘输入（截屏由手机端按钮触发，避免快捷键被监考软件记录）：

1. 「设置 → 手机显示」打开开关，出现二维码与访问地址（含配对码，防止同网络他人接入）
2. 手机连同一 Wi-Fi 扫码打开；返回主界面后电脑窗口自动隐藏
3. 手机端可：截屏解题 / 追加截图 / 深度思考 / 切换场景 / 全屏纯显示（竖屏锁定）/ 屏幕常亮 / 追问 / 显隐电脑窗口

> 推荐手机端使用 Chrome / Edge / Safari；窗口隐藏后可用「隐藏/显示窗口」快捷键或手机端按钮恢复。

### 5. （可选）实时面试助手

「设置 → 面试实时助手」开启（或手机端「🎙 实时助手」）：持续监听面试官说话，静音 + 问句特征自动判定「问完了」，无需任何按键即实时生成建议回答。电脑悬浮窗与手机端都会显示「🎙 问题 → 建议回答」时间线，转写内容实时可见。

> 建议音频输入选「系统音频」只听面试官（macOS 自动用麦克风）。依赖语音转录的百炼 Key。

## 默认快捷键

macOS 修饰键为 `⌥ Option(Alt)`，Windows/Linux 为 `Ctrl`；所有快捷键均可在「设置 → 快捷键」中自定义（Windows 上若自定义成 `Alt` 组合，会自动附带注册 `Ctrl+Alt` 变体）。

| 功能 | macOS | Windows / Linux |
| ---- | ----- | --------------- |
| 截屏解题 | `Alt+Enter` | `Ctrl+Enter` |
| 追加截图（长题分屏） | `Alt+Shift+Enter` | `Ctrl+Shift+Enter` |
| 停止生成 | `Alt+.` | `Ctrl+.` |
| 隐藏 / 显示窗口 | `Alt+H` | `Ctrl+H` |
| 鼠标穿透开关 | `Alt+M` | `Ctrl+M` |
| 切换提示词场景 | `Alt+P` | `Ctrl+P` |
| 切换供应商方案 | `Alt+O` | `Ctrl+O` |
| 语音转录开关 | `Alt+T` | `Ctrl+T` |
| 清除转录文本 | `Alt+Shift+T` | `Ctrl+Shift+T` |
| 答案区上 / 下滚动 | `Ctrl+J` / `Ctrl+K` | 同左 |
| 移动窗口（200px 步长） | `Ctrl+方向键` | 同左 |

## 常见疑问

**Q：语音识别转文字后，怎么让 AI 自动解答？**

- 想要**全自动**：开启「实时面试助手」（设置 → 面试实时助手，或手机端 🎙 按钮）。它持续监听转写，判定面试官问完后自动生成建议回答，无需任何按键。
- 想要**手动控制**：开着语音转录（`Alt+T`），在需要时按截屏快捷键（`Alt+Enter`）——转写文字会作为题目上下文随截图一起提交。
- 只开语音转录、不截图，是不会触发解答的：手动链路以截图为核心，纯语音自动应答由实时面试助手负责。

**Q：解题助手窗口隐藏了，截屏也截不到窗口？**

截屏的目的就是截「屏幕上的题目」，本工具窗口本来就不应该出现在截图里——它被主动排除在所有屏幕捕获之外，这也是共享屏幕时对方看不到它的原因。窗口隐藏同样不影响解题：截图照常生成、解答照常推送（手机模式下直接到手机）。想在电脑上看答案，用「隐藏/显示窗口」快捷键、手机端「显示电脑窗口」按钮或系统托盘图标找回窗口即可。

**Q：分享屏幕时对方能看到应用吗？**

大部分会议软件（如腾讯会议）下不可见，但少数软件和浏览器可能无法正常隐身。正式使用前请务必用「当前电脑 + 当前会议软件」实测。

## 从源码运行与打包

技术栈：Electron 37 + electron-vite、React 19 + TypeScript、Tailwind CSS v4 + shadcn/ui、Zustand、Vercel AI SDK（任意 OpenAI 兼容接口）。

```bash
$ npm install        # 安装依赖
$ npm run dev        # 开发模式启动
$ npm run typecheck  # 类型检查
$ npm run build      # 类型检查 + 构建
$ npm run build:mac  # 打包 macOS 安装包
$ npm run build:win  # 打包 Windows 安装包
```
